# M9 — Gemma 4n Prompt Library
> Module 9: Final Project & Oral Defense

---

## Template 1 — SCAFFOLD project brief
```
SCAFFOLD: I need to write my DataPath M9 project brief.
My dataset: [name and brief description]
My initial question: [what you're exploring]
Give me a skeleton for the 9-question brief template, with guidance notes in each section telling me what a strong answer looks like (but leave the actual answers blank for me to fill in).
```

## Template 2 — EXPLAIN baseline model
```
EXPLAIN: What is a baseline model and why do I need one?
My level: [Beginner / Developer]
My project type: [regression / classification]
Show me: how to create a DummyRegressor or DummyClassifier, how to evaluate it, and how to report it in my presentation.
```

## Template 3 — SCAFFOLD presentation structure
```
SCAFFOLD: I need to structure my final presentation using the Pyramid Principle.
My key finding: [state it in one sentence]
My supporting findings: [list 2–3 things you found]
Give me a 7-slide outline with a one-line description of what each slide should contain.
```

## Template 4 — REVIEW my README
```
REVIEW: [paste your README.md]
Check: Does the opening paragraph state the question and key finding? Is there a "how to run" section? Is it readable by someone who has never seen my project?
Suggest 3 specific improvements.
```

## Template 5 — SCAFFOLD limitations section
```
SCAFFOLD: I need to write a genuine limitations section for my project on [topic].
Dataset: [brief description]
Method: [what you did]
Give me 4 prompts — one for each category (data coverage, methodological assumptions, confounders, generalisability) — that I should answer in my own words.
I will write the actual answers myself.
```

## Template 6 — Oral defense practice
```
REVIEW: I am preparing for my oral defense. Ask me the 3 hardest questions from the M9 oral defense question list, one at a time, and evaluate my answers for clarity and depth.
My project: [1-sentence description]
Start with: "What are the three main limitations of your analysis?"
```
